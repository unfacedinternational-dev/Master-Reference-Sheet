1. HTML Input Types & Form Fields

All standard <input> element variations for handling user entry, validation, and controls.

Input Type Syntax Example Description & Usage
text<input type="text" name="usr">Standard single-line text input field
password<input type="password" name="pwd">Masks entered characters for security
email<input type="email" name="eml">Includes built-in email format validation
number<input type="number" min="1" max="10">Numeric entry with step arrows
tel<input type="tel" name="phone">Telephone number field (opens dialpad on mobile)
url<input type="url" name="web">URL field requiring valid web address formatting
search<input type="search" name="q">Search bar with built-in clear (X) button
date<input type="date" name="dob">Native calendar date selector
time<input type="time" name="t">Native time picker
datetime-local<input type="datetime-local">Combined local date and time picker
month<input type="month" name="m">Month and year selector
week<input type="week" name="w">Week number and year selector
color<input type="color" name="hex">Native pop-up color wheel picker
range<input type="range" min="0" max="100">Slider control for selecting values within a range
checkbox<input type="checkbox" value="1">Toggle box for single/multiple selections
radio<input type="radio" name="g" value="a">Radio button (selects 1 option from a shared group name)
file<input type="file" accept="image/*">File upload selector
hidden<input type="hidden" value="123">Stores invisible state/ID data in the form
submit<input type="submit" value="Send">Button that sends form data to server
reset<input type="reset" value="Clear">Resets all form controls back to default
image<input type="image" src="btn.png">Graphical image used as a submission button

3. Accessibility (WAI-ARIA) & Focus Control

Attribute / Role Purpose Usage Example
role="..."Defines semantic type for custom non-standard tags.<div role="button">Click</div>
aria-labelGives accessible text names to icon buttons.<button aria-label="Close">X</button>
aria-expandedInforms screen readers if a dropdown/accordion is open.<button aria-expanded="false">
aria-liveAnnounces dynamic page changes automatically.<div aria-live="polite">
tabindex="0"Puts non-interactive elements into the keyboard Tab sequence.<div tabindex="0">Focusable</div>

4. Interactive Widgets, Popups & Gauges

<!-- Native Disclosure Accordion -->
<details open>
  <summary>Accordion Title</summary>
  <p>Toggleable text visible without JS libraries.</p>
</details>

<!-- Native Dialog Overlay -->
<dialog id="myModal">
  <p>Native top-layer popup modal window.</p>
  <button onclick="document.getElementById('myModal').close()">Close</button>
</dialog>

<!-- Auto-Complete Suggestions -->
<input list="opts">
<datalist id="opts">
  <option value="Option 1">
  <option value="Option 2">
</datalist>

<!-- Gauges & Progress Indicators -->
<progress value="70" max="100">70%</progress>
<meter value="0.6" min="0" max="1" low="0.3" high="0.8">60%</meter>

5. Performance & Resource Loading

<!-- Pre-connect to external servers (CDNs/Fonts) -->
<link rel="preconnect" href="https://fonts.googleapis.com">

<!-- Pre-load high-priority assets early -->
<link rel="preload" href="hero.webp" as="image">

<!-- Script Execution Attributes -->
<script src="analytics.js" async></script> <!-- Async execution -->
<script src="app.js" defer></script>       <!-- Defer until HTML parsed -->

6. Modern Global Attributes & Popover API

<!-- Machine-Readable Data Annotations -->
<p>Price: <data value="29.99">$29.99</data></p>
<p>Date: <time datetime="2026-10-31T20:00">Halloween 8 PM</time></p>

<!-- Native Popover API (No JS Z-index required) -->
<button popovertarget="pop-box">Toggle Popover</button>
<div id="pop-box" popover>Top-Layer Native Popover Content</div>

<!-- Inline Text Editing & Word Break -->
<div contenteditable="true">Editable area text</div>
<p>Long<wbr>word<wbr>break<wbr>opportunity.</p>
